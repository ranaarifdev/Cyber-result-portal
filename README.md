## Open

Open `preview.html` in a browser and select a design, or open any `cv-XX/index.html` directly.

## Print or save as PDF

1. Open a CV in Chrome, Edge, or another modern browser.
2. Choose **Print** and select **Save as PDF**.
3. Use paper size **A4**, scale **100%**, and **no browser margins**.
4. Enable **background graphics** and disable browser headers and footers.

All pages are fixed at 210 mm × 297 mm and include print-color preservation rules. Photo-led layouts use the verified `student picture.jpg` image supplied in the project folder.
