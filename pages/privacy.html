Data protection

Privacy notice

The portal performs exact roll-number searches in your browser. It sends no search query to an API, uses no analytics, stores no search history, and includes no advertisements.

Important static-hosting limitation

This is a static website. Its local JSON file is neither encrypted nor access-controlled. If published through GitHub Pages or another public host, anyone who can access the website can potentially download and inspect all static data files—even though the interface does not list students.

Recommended use

Keep publicMode disabled and use the portal locally or on an appropriately protected host unless publication of the records has been formally authorized. Browser print and save-to-PDF features operate locally.
